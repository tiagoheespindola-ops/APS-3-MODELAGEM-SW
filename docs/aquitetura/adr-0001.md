# ADR 0001 — Utilização do RabbitMQ para Envio de Alertas

## Status
Aprovado

## Contexto

O sistema precisa identificar situações de desperdício
de energia nos laboratórios e avisar a gestão do campus.

Quando o consumo estiver elevado e não houver pessoas
ou sessão ativa no laboratório, o sistema deverá
registrar a ocorrência e enviar uma notificação.

É importante que o envio dos alertas não atrapalhe
o monitoramento dos ambientes.

## Decisão

Foi escolhido o RabbitMQ para realizar o envio
de mensagens de forma assíncrona.

Quando o sistema identificar um desperdício,
ele registrará a ocorrência e enviará uma mensagem
para o serviço responsável pelas notificações.

Esse serviço ficará responsável por encaminhar
o alerta para a gestão do campus.

## Consequências

### Vantagens

- O envio dos alertas não bloqueia o monitoramento.
- Os serviços ficam menos dependentes entre si.
- É possível tentar enviar mensagens novamente
  em caso de falhas.
- Facilita futuras melhorias no sistema.

### Desvantagens

- Exige configuração e manutenção.
- Pode ocorrer atraso no envio das notificações.
- É necessário evitar o envio duplicado de alertas.
- Adiciona mais um serviço à arquitetura.

## Conclusão

A utilização do RabbitMQ foi escolhida porque
facilita o envio de alertas e permite que o sistema
continue monitorando os laboratórios enquanto
as notificações são processadas.
